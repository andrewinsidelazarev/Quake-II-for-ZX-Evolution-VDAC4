# Ядро «бомж-3D» 0.02 (Quake 2 для VDAC4) — выпуск 24.11.2026

Ядро ПЛИС Tang Nano 20K (GW2AR-18) для Quake 2: ESP32-S3 готовит кадр, ядро рисует его в SDRAM и выводит
на HDMI. Формат команд — `gpu/SPEC.md` (версия 0.4). Регистр VERSION по LINK — `0x51010002` ('Q', протокол
LINK 1, ядро 0.02). Метка ядра для BL616 (user code) — `0x56443451` («VD4Q»).

На плате **не проверялось**: ни разу не загружалось.

## Что нового против 0.01 (сборка d)

- SPEC 0.4: команда `MARK` (число в регистр MARK, когда всё до неё выполнено) и чтение SDRAM мимо очереди
  команд — регистры `RD_ADDR` (0x88), `RD_LEN` (0x8C), `STATUS` бит 6, `MARK` (0x90), окно 4 КБ
  (0x1000…0x1FFC). Модуль `bz_rdwin.sv`. Зачем: Q2.ELF держит кадры анимации моделей md2 в SDRAM ядра.
- Тайминг: буфер на две точки (`bz_skid`, в `bz_gpu.sv`) между растеризатором/ядром и конвейером точки —
  готовность конвейера больше не идёт в разрешение тактов растеризатора; параметры банка у конвейера точки
  на ступени B — из регистров (`bz_pix.sv`), а не выбором по номеру банка. Без этих двух правок ядро 0.02
  (сборка e) не проходило тайминг: clk_mem 56,3 МГц, clk_sd 113,6 МГц.

## Что проверено

- Модель C (`gpu/model/bomzh.c`) против RTL на стенде Verilator `gpu/rtl/tb/tb_gpu.cpp` (настоящий мост
  SDRAM sd_bridge): трасса демо q2demo1 с кадрами md2 в хранилище (2017 порций, 45 MARK, 69 записей в верх
  SDRAM) — после каждой порции вся память RTL = память модели, регистр MARK = модели, копия SDRAM в окно,
  запущенная посреди рисования, = памяти модели. Итог прогона — ниже.
- Тот же протокол в эмуляторе Unreal NG (C-модель ядра): демо 1 на base2 и демо 2 на waste2 проходят.
- На ПК (q2esp): кадр модели ядра совпадает с ref_bz во всех детерминированных сценариях.

Итог стенда RTL (24.11.2026, полный прогон трассы демо с хранилищем): ПРОШЛО — 2017 кадров, память RTL =
памяти модели; 2 200 873 454 такта (17,96 мс на кадр на 60,75 МГц), 6,72 такта на точку растра (стоп
конвейера: тексель 0,461, z 3,355, цвет 0,122); контроллер SDRAM занят 34,2 % тактов clk_sd; копий SDRAM в
окно посреди рисования — 1074 (172 640 байт), все совпали с моделью.
