## Что нового против 0.02

- **FIFO_FREE без мусора на LINK.** Раньше 0x0C отдавал прямо выход вычитателя очереди (домен clk_mem), а
  fb_link брал слово по фронту link_sck без синхронизации: захват посреди смены счётчика давал смесь битов
  (на плате ESP 0.1.167 прочитала 0x858 при очереди в 2048 слов). Новый регистр **0x1C FREE_GRAY** =
  `{0x47 'G', 12'd0, FIFO_FREE в коде Грея}` — из регистра clk_mem. FIFO_FREE за такт меняется не больше чем
  на 1, а соседние числа в коде Грея отличаются одним битом — захват даёт старое или новое число. Q2.ELF с
  ядром 0.03 читает 0x1C (метка 0x47 и нули в битах 23:12 — проверка чтения). 0x0C — как у 0.02.
- **FIFO_FREE не уходит в минус** (`bz_fifo.sv`). Если ESP запишет больше места (испорченное чтение), память
  заполняется целиком при занятом выходном слове, и разность была −1 = 0xFFF («4095 свободно»). Теперь — 0.
- **Тайминг: запись цвета в ступени F без общего adv** (`bz_pix.sv`, f_wr / f_done). Первая сборка 0.03 не
  прошла: путь «метки кэша текстур (BSRAM) → сравнение → st_d → adv → разрешение записи куска цвета c_d»,
  13 уровней, −0,202 нс. Теперь F пишет точку один раз, как только сама готова (st_f = 0); значение то же —
  пока точка стоит, всё, от чего зависит f_out, неподвижно. Число тактов на кадр не изменилось.
- Двоичный регистр под 0x0C убран после сборки b (с ним — 35 неразведённых цепей; кристалл заполнен на 96 %).
