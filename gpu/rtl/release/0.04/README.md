# Ядро «бомж-3D» 0.04 (Quake 2 для VDAC4) — выпуск 27.11.2026

Ядро ПЛИС Tang Nano 20K (GW2AR-18) для Quake 2. Формат команд — `gpu/SPEC.md` (0.4), как у 0.03. Регистр
VERSION по LINK — `0x51010004` ('Q', протокол LINK 1, ядро 0.04). Метка ядра для BL616 — `0x56443451` («VD4Q»).

## Что нового против 0.03

- **Ножницы растеризатора со знаком** (`bz_raster.sv`, отрезок строки). Выборка части `scx0[15:0]` в Verilog
  беззнаковая, и края отрезка сравнивались с окном без знака: край левее окна (l < 0) не зажимался, а
  отрезок целиком левее окна (r < 0) зажимался справа и рисовался на всю строку. ESP с отсечением граней
  без клиппинга (вершины левее окна) давал на 0.03 полосы на весь экран; стенд tb_raster на трассе demo1 с
  такими гранями — расхождение в кадре 124 (l = −51). С 0.04 вершины левее окна допустимы.
- **Тайминг: ступень H в конвейере точки** (`bz_pix.sv`). Первая сборка 0.04 (только ножницы) не прошла:
  clk_mem 55,1 МГц, 268 путей до −1,7 нс — «метки кэша текстур с выхода BSRAM → сравнение → st_d → adv →
  разрешение сотен регистров» (буфер bz_skid, кусок z, умножители). Опции Gowin (place 0/1, replicate,
  retiming) в Education ничего не меняют. Теперь метки сравниваются в новой ступени H, в D попадание
  приходит из регистра. Точка, стоявшая в H во время догрузки строки, читает кэш повторно (t_rpl, такт
  после записи метки) — иначе соседняя точка той же строки промахнулась бы ещё раз. Промах длиннее на такт,
  конвейер — на ступень (8 вместо 7).
- **Тайминг: «строки кончились» — регистр** (`bz_raster.sv`, e_fin, состояние E_CHK). Сравнение 32 бит
  ey ≥ ey1 стояло прямо в условии E_RUN и разрешало весь такт рёбер и отрезка (−1,4 нс). Такт на
  многоугольник больше.

  посреди рисования 1286 — все совпали; city3 — ПРОШЛО, 2115 кадров, 14,26 мс на кадр, копий 1643 — все
  совпали.
- Цена правок тайминга (ступень H, флаг e_fin) — тот же стенд tb_gpu на тех же трассах, база — 0.03 только с
  исправлением ножниц (E:\zx\cache\tmp\gpu_base03): demo1 — 2 520 068 855 → 2 527 448 780 тактов (+0,29 %,

- Плата (прошивка ESP 0.1.177–0.1.180, 27–28.11.2026): «core Q2 runs: VERSION 51010004», LINK check ok, Quake 2

  уронил прошивку (двойное освобождение в zm-coreload при записи ядра в кэш) — исправлено в прошивке 0.1.179.
